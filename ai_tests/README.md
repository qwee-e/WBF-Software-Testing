# 模块二 AI 自动化测试

被测源码保持原样。测试采用性质断言；复杂输入不编造固定融合坐标。

## 安装与执行（项目根目录，PowerShell）

```powershell
python -m venv .venv-ai
.\.venv-ai\Scripts\python.exe -m pip install -r requirements-ai.txt
.\.venv-ai\Scripts\python.exe run_ai_tests.py
# 单条或部分用例
.\.venv-ai\Scripts\python.exe run_ai_tests.py --case 001
```

运行结果默认写入 `ai_test_results/AI-WBF-编号/`。正式提交的执行记录放在
`docs/module2/results/`，再次运行默认不会覆盖它。运行器保留 pytest 的失败退出码。
每个文件代表一条设计用例；Hypothesis 的多个有效输入不额外计作用例条数。

## 016 搜索与反例

主验证域使用 1～6 个模型、每模型 0～20 个框、0～9 的类别、正面积归一化框。
基准分数 .01～1、权重 .5～4；数值变异允许分数扩展到 1e-8，权重扩展到 1e-6～1e6。
至少 90% 候选用于主验证域；另外 10% 使用 1e-100 / 1e200 权重，仅作数值风险探索。
随机种子池结合 10 种结构变异：模型增删、重复框、密集重叠、空模型、标签双射、排列、近阈值框、数值缩放、过滤参数、框增删。
正权重和分数、三列表对齐等输入前提会在调用前校验，丢弃和有效数量分别记录。

输出检查覆盖崩溃、finite、形状、几何合法性、类别来源及分数范围。`avg + allows_overflow=True`
允许分数超过 1，不误报；其他组合的分数上界容差为 1e-6。
失败后继续搜索，按“输入域、性质、模式、开关”分组缩减，不把这些组的数量当作独立 Bug 数。
缩减保持原数值，只删除框或模型，直到不能再单次删除；每个缩减结果再次重放两次。

- `search_trace.jsonl`：所有候选的种子、序号、变异、输入哈希及判定。
- `failure_inputs.jsonl`：所有违反性质的完整输入和输出，包括附加探索域。
- `evidence.json`：统计、前三个输入、分组代表、缩减结果、主验证/探索分类。
- `development_results/`：150 次调试；`results/`：3,000 次正式结果。两者不合并计数。

重放正常域的已知失败（正式记录中的第 6 号数组元素）：

```powershell
.\.venv-ai\Scripts\python.exe replay_ai_evidence.py docs/module2/results/AI-WBF-016/evidence.json --finding 6
```

重放工具退出 0 表示复现了保存的失败或观察，**不表示该性质通过**。
正式 016 保留真实 `FAIL` 和退出码 1，不用 `xfail` 隐藏已知问题。

调试时可降低预算，完成后删除环境变量恢复默认：

```powershell
$env:AI_FUZZ_CANDIDATES = '150'
.\.venv-ai\Scripts\python.exe run_ai_tests.py --case 016
Remove-Item Env:AI_FUZZ_CANDIDATES
```

本轮 014/016 采用自定义种子化变异和删除缩减；未使用 Hypothesis 的缩减器。
Hypothesis 用于六条严格变形测试。完整结果与方法限制见[执行记录](../docs/module2/执行记录.md)。

## 输入与断言边界

`support.stable_inputs` 构造 2～6 个模型、1～3 个类别、1～3 个强分离簇。
框模板宽高 .09，端点抖动不超过 .002；簇内任意合法加权中心与原始框的 IoU
下界超过 .69，阈值最大 .60；异簇无交集。各框有效分数 `score * weight`
互不相同，因此顺序变换不会改变贪心选择次序。对并列分数及桥接簇另行探索。
权重在 .5～4，原始分数在 .01～1，过滤阈值从 0/.02/.05/.1 取样。每条 Hypothesis 测试另加 8 个明确锚点，保证四种置信度模式及两种溢出设置的全部组合确实执行。

比较时先验证 finite、数组形状及几何合法性，再对 `(box, score, label)` 做一对一匹配。
标签精确比较；坐标和分数使用 `atol=1e-6, rtol=1e-5`。不依赖输出行序，也不分别排序三类数组。
这是当前测试所需的公共比较接口，后续可由其他用例复用。

Hypothesis 固定版本和种子，关闭示例数据库及耗时截止。
`function_scoped_fixture` 健康检查仅针对跨生成样本累计证据的 `audit` 禁用；它不改变输入或算法状态。
保留实际生成次数、配置计数、前三组完整比较输入和所有失败证据；不把采样通过解释为全输入域证明。
