# 测试04类别隔离及06低IoU不融合

被测对象为 `ensemble_boxes/ensemble_boxes_wbf.py` 中的 `weighted_boxes_fusion()`。用例方向来自模块1人工测试设计框架的 04、06，采用固定输入并在执行前计算预期。测试数据分别保存在 [WBF-04.json](../test_data/WBF-04.json)、[WBF-06.json](../test_data/WBF-06.json)，脚本为 [test_wbf_04_06.py](test_wbf_04_06.py)。

## 公共配置与判定

两个模型各输入一个合法框，分数分别为 0.9 和 0.8，权重 `[1,1]`，`iou_thr=0.55`、`skip_box_thr=0.0`、`conf_type='avg'`、`allows_overflow=False`。

两例均预期输出两个独立簇，每簇仅一个模型贡献。在默认 avg 模式下，分数仍需按模型覆盖情况缩放：`0.9×1/2=0.45`、`0.8×1/2=0.4`，不能把原始分数直接作为预期。坐标保持不变，按最终分数降序输出。

断言检查框数量、四维坐标、最终分数、类别、三个数组形状及无警告行为。坐标和分数容限为 `rtol=0, atol=1e-6`，类别按数值精确比较。

## 04 坐标完全相同但类别不同

测试方法：场景法。两个框均为 `[0.1,0.1,0.5,0.5]`，类别分别为 1 和 2。面积、交集和并集均为 0.16，IoU=1，超过阈值；但类别不同，应隔离为两个输出，不能跨类别融合。

预期与实际输出一致：

```text
boxes  = [[0.1,0.1,0.5,0.5], [0.1,0.1,0.5,0.5]]
scores = [0.45,0.4]
labels = [1.0,2.0]
```

形状为 `(2,4)`、`(2,)`、`(2,)`，无警告。判定：**PASS**。

## 06 同类别且IoU明显小于阈值

测试方法：等价类。两个框分别为 `[0.1,0.1,0.5,0.5]` 和 `[0.4,0.4,0.8,0.8]`，类别均为 1。每框面积为 0.16，交集为 `0.1×0.1=0.01`，并集为 `0.16+0.16-0.01=0.31`，故 `IoU=1/31≈0.032258<0.55`。

这里选取部分重叠的框，覆盖正 IoU 但低于阈值的情况，与 03 的完全不重叠场景区分。两个框应保留为独立输出。

预期与实际输出一致：

```text
boxes  = [[0.1,0.1,0.5,0.5], [0.4,0.4,0.8,0.8]]
scores = [0.45,0.4]
labels = [1.0,1.0]
```

形状为 `(2,4)`、`(2,)`、`(2,)`，无警告。判定：**PASS**。
