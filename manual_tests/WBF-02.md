# WBF-02 双模型完全相同且同类别的框

测试对象：`ensemble_boxes/ensemble_boxes_wbf.py` 中的 `weighted_boxes_fusion()`。
测试方法：场景法。目的：验证两个模型的完全重合同类框融合为一个框，且坐标、平均置信度、类别及输出形状符合预期。

## 设计与预期

设计来源：`wbf_模块1_人工2.0.docx` 的编号 02。输入及脚本采用 AI 辅助建议，工具协助执行，需本人复核；不描述为未经辅助的独立人工设计或执行。预期值在执行前按以下计算确定，未使用实际输出反推预期。

| 参数 | 输入 |
| --- | --- |
| boxes_list | `[[[0.1,0.1,0.5,0.5]], [[0.1,0.1,0.5,0.5]]]` |
| scores_list | `[[0.9], [0.8]]` |
| labels_list | `[[1], [1]]` |
| weights | `[1,1]` |
| iou_thr / skip_box_thr | `0.55` / `0.0` |
| conf_type / allows_overflow | `'avg'` / `False` |

两个框面积均为 `(0.5-0.1)×(0.5-0.1)=0.16`，交集和并集面积均为 0.16，故 IoU=1，大于 0.55。类别相同且两个分数均高于过滤阈值，应融合为一个框。

对任意坐标分量 x，加权融合结果为 `(0.9×1×x+0.8×1×x)/(0.9×1+0.8×1)=x`，因此坐标不变。两模型等权且各贡献一个框，默认 avg 的最终分数为 `(0.9+0.8)/2=0.85`。

预期 boxes=`[[0.1,0.1,0.5,0.5]]`、scores=`[0.85]`、labels=`[1]`；形状分别为 `(1,4)`、`(1,)`、`(1,)`。合法输入不应产生警告。坐标和分数采用 `rtol=0, atol=1e-6`，类别比较数值，不强制整数 dtype。
