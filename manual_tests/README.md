# 模块1自动化测试

当前覆盖用例编号01至30。统一运行：

```powershell
python run_tests.py
```

首次运行可在项目根目录双击 `run_tests.bat`，自动创建独立环境、安装依赖并执行全部用例。详细环境要求、运行命令、退出码与已知失败说明见 [自动化测试工程说明](../docs/自动化测试工程_README.md)。独立交付包中的同一说明位于根目录 `README.md`。

共有30个用例编号、31个pytest实例（08含两个参数化场景）。当前统一运行结果为23个编号通过、7个失败；按实例统计为24通过、7失败。失败编号23、24、25、26、27、28、30保留真实断言，不改成通过。

`member_a/` 与根目录的 `test_wbf_*.py` 是既有测试的组织方式，不影响统一执行。`results/` 以及 `member_a/results/` 保留历史执行证据，新的一键运行结果位于项目根目录 `test_results/时间戳/`。
