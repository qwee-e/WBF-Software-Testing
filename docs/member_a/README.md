## 三项NG的解释

- [23：SystemExit](../../defects/member_a/WBF-UT-023.md)：与建议的ValueError健壮性契约不符；异常行为已复现，缺陷定性待评审。
- [25：IndexError](../../defects/member_a/WBF-UT-025.md)：维度错误未显式校验；与建议的ValueError契约不符，缺陷定性待评审。
- [26：NaN坐标](../../defects/member_a/WBF-UT-026.md)：两个零分同类重合框实际返回四个NaN坐标，数值问题已复现。

这些失败保留为NG，不使用xfail、修改预期或修改算法将其变成通过。再次运行全部成员一测试，在相同源码和环境下预期仍会出现这3项失败。
