# AI-WBF-003 模型权重整体同比缩放测试

## 测试目标

验证所有模型权重乘以同一个正数后，`weighted_boxes_fusion()`的融合框、最终分数和类别保持不变。该关系检查各置信度模式是否只依赖模型权重的相对比例。

## 输入与执行方法

- 覆盖 `avg`、`max`、`box_and_model_avg`、`absent_model_aware_avg` 四种模式。
- 每种模式生成100组固定种子输入，共400组源输入。
- 模型数量为2至6，权重范围为0.5至4.0。
- 缩放倍率取 `2^-10` 至 `2^10` 范围内的2的整数次幂。
- 每组包含两个类别、四个强分离簇；簇内框保持高重叠，簇间框完全分离。
- 变换时只同比缩放权重，不改变框、分数、类别、阈值或其他参数。

执行命令：

```bash
python -m pytest ai_tests/test_ai_wbf_003.py -v -s
```

## 判定规则

缩放前后必须满足：

1. 输出数组形状一致，所有数值均为有限值。
2. 将框、分数和类别作为完整记录进行排序匹配，不能分别重排三个数组。
3. 类别精确一致。
4. 框坐标和最终分数在 `rtol=1e-5、atol=1e-6` 范围内一致。

## 实际结果

四种模式全部通过，400组源输入均满足权重同比缩放不变量。测试观察到的最大坐标绝对误差和最大分数绝对误差均为 `0.0`。本项未发现新的稳定反例，未修改被测算法。

JUnit结果及执行环境见 `results/ai_wbf_003/`。
